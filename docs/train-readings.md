# 全車両の読み上げ用表記

2026-09-16に `data/trains.json` の全110件（109名称）を点検。形12件、型2件（改良型を含む）、系65件、英字を含む名前48件を確認した。分類には重複がある。図鑑専用の蒸気機関車3件も含めている。

前回の6路線の部分置換では、形・型・系、数値、英字愛称、漢字の読みが残った。今回は `js/train-readings.js` に名前全体をかなで登録し、全件再生・個別再生の共通入口で変換する。表示・形式・愛称・路線・塗装・番台・号機・編成の情報と、読み上げ速度1.0を維持する。

## 点検したパターン

| パターン | 採用する読み方・注意点 |
| --- | --- |
| 数字＋形／型 | がた。8000型は「はっせんがた」。系と混同しない |
| 数字＋系 | けい。8000系は「はっせんけい」 |
| 日本語の数値 | 300＝さんびゃく、600＝ろっぴゃく、800＝はっぴゃく、3000＝さんぜん、8000＝はっせんなどの音変化も明記 |
| 先頭ゼロ | 0系＝ぜろけい、001系＝ぜろぜろいちけい。先頭ゼロを捨てない |
| ハイフンを含む形式 | 10-300＝いちまんさんびゃく、12-600＝いちまんにせんろっぴゃく。引き算や別々の数値として読まない |
| E/H/N/EF/EH/C/D | 日本語の文字名＋通常の数値読み。D51を愛称の「デゴイチ」に置き換えず、でぃーごじゅういちと読む |
| N700A／N700S | えぬななひゃくえー／えぬななひゃくえす。表示にない「系」を足さない |
| L0／T3／SL／AE | えるぜろ／てぃーさん／えすえる／えーいー。Oと0を混同しない |
| GSE/MSE/VSE/LSE/RSE/NSE | じー／えむ／ぶい／える／あーる／えぬ ＋ えすいー |
| EXE／EXEα／HiSE | えくせ／えくせあるふぁ／はいえすいー。機械的な一文字ずつの読みは使わない |
| PRiVACE／Max／next／X／Osaka Metro | ぷらいべーす／まっくす／ねくすと／えっくす／おおさかめとろ |
| 漢字の路線・事業者・愛称 | 山手線＝やまのてせん、常磐線＝じょうばんせん、伊予灘＝いよなだ、三田線＝みたせん、高尾山＝たかおさんなど、全文をかなへ変換 |
| 番台・号機・編成 | せんばんだい／にせんばんだい／にひゃくごうき／てぃーさんへんせいなど。車両の区別を残す |
| 塗装・補足 | 通常色＝つうじょうしょく、黄色＝きいろ、うぐいす色＝うぐいすいろ、反転塗装＝はんてんとそう。括弧内も省略しない |

## 根拠と確認範囲

全件について表示名と読みを対にして、数値・形式・固有名詞・補足の欠落がないか見直した。通常の漢字・数値は日本語の標準的な読みとして登録したもので、全110件の全文読みを鉄道会社が公式指定していると主張するものではない。数字を一桁ずつ読む慣用や愛称など、他の有効な読みを誤りとは扱わない。

公式資料で直接確認した表記・読み：

- [小田急キッズ・電車ずかん](https://www.odakyu.jp/kids/train/)：「形」のふりがな、GSE・MSE・EXE・EXEαの読み。
- [小田急EXE・EXEα](https://www.odakyu.jp/romancecar/features/line_up/30000/)：エクセ／エクセアルファ。
- [阪急PRiVACE](https://www.hankyu.co.jp/privace/index.html)：プライベース。
- [JR東海のL0系発表](https://jr-central.co.jp/news/release/nws000625.html)：エル・ゼロ。
- [西武ラビュー](https://www.seiburailway.jp/railway/reservedtrain/laview/)：001のゼロ2桁を含む形式と命名の理由。[西武キッズ](https://kosodate.seiburailway.jp/kids/museum/zukan/001/)でも001系表記を確認。
- [東武車両紹介](https://www.tobu.co.jp/corporation/rail/vehicles/)：8000型の「型」の表記。
- [JR四国](https://www.jr-shikoku.co.jp/01_trainbus/event_train/seat_info/iyonadamonogatari)：伊予灘ものがたり／Iyonada Monogatariの併記。
- 山手線・常磐線は前回確認した[JR東日本教材](https://www.jreast.co.jp/id/akita/ietetsu/doc/accum-a.pdf)の読みを継承。

公式ページにふりがなを見つけられなかった特殊形式・旧愛称は、次の資料で読みを補足した。公式の発音確認とは区別する。

- [西武の発表会を取材した記事](https://travel.watch.impress.co.jp/docs/news/1150474.html)：社長による001（ゼロゼロイチ）系の発表。
- [日本大学理工学部鉄道研究会の車両解説](https://nrtetsudouexp41.ojaru.jp/C/C-takahashi.html)：10-300形（いちまんさんびゃくがた）。
- [大江戸線の車両解説](https://w.atwiki.jp/aniwotawiki/pages/53861.html)：12-600（いちまんにせんろっぴゃく）形。公式資料から確認できたのは[12-600形の表記](https://www.kotsu.metro.tokyo.jp/about/koukai/vehicle_outline/oedo_12-600_02_outside.pdf)まで。
- [鉄道車両の取材記事](https://jbpress.ismedia.jp/articles/-/83757)：HiSE（ハイエスイー）。

全件の実音声を聴取した検査ではない。iPhone／iPad実機Safariでの音量・アクセント・区切り・速度感は未確認。文字列が正しくても、端末内の音声エンジンによる発音品質の違いは残る。

## 更新と回帰検証

名前を追加・変更したら、表示名と一致するキー・読みを `js/train-readings.js` に追加し、この一覧も更新する。`tests/train-readings.test.mjs` が全公開データとのキー一致、かなのみの読み、形式接尾辞、異なる名前が同音に潰れないことを検査する。アプリのテストは110件すべてで全件再生と聞き直しを通し、音声APIに渡る文字列がかなのみで、表示名は維持されることを確認する。

未登録の名前は画面操作を止めないため表示名へ戻すが、現在の全110件にその経路はない。車両追加時に辞書を更新し忘れるとテストが失敗する。写真の出典・seed・公開JSON・データ生成CLIは変更しない。
