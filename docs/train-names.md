# 車両の呼び名と表記

形式名だけでは分からないというフィードバックに対応し、子どもが知っている列車名や路線名を併記する。新幹線は「E5系新幹線はやぶさ」「E6系新幹線こまち」と同じ「形式名＋新幹線＋呼び名」の順にし、塗装などの補足は末尾の括弧内に付ける。

登録110件すべての名前を点検し、当初の新幹線4件に加え、以下の4件も修正した。表示名8件を修正、102件を維持。全件の判定は[車両名点検台帳](train-name-audit-2026-09.md)に記録した。既に親しまれている呼び名や路線名がある車両は維持し、担当する全列車名の列挙は行わない。

| ID | 表示名 |
| --- | --- |
| `500-nozomi` | 500系新幹線こだま・のぞみ（通常色） |
| `n700` | N700系新幹線のぞみ・ひかり・こだま |
| `n700a` | N700A新幹線のぞみ・ひかり・こだま |

| `e233-shonan` | E233系東海道線・高崎線・宇都宮線 |

列車名は車両の形式名と一対一ではない。形式と通常色の表記を残し、同じ呼び名の別形式やハローキティ新幹線と区別する。500系の図鑑では「むかしは のぞみ」と説明し、現在の「こだま」の区間と、かつての「のぞみ」の区間を分けて記載する。0系・E4系は引退車両として過去形にする。E3系の表示名は1000番台と2000番台で表記を統一し、正式名と商品名の「番代」は出典の表記を維持する。E231系・E233系は同じ路線名でも形式番号で区別し、湘南色の説明を図鑑に残す。

点検で確認した説明の不整合も修正した。N700・N700Aは東海道・山陽の16両編成として東京〜博多の説明に揃え、N700の運行会社と「みずほ・さくら」の8両編成との比較を同期した。快速アクティー211系は「あつぎ」とドアの誤記を修正し、Osaka Metro中央線400系は帯色をみどりに修正した。近鉄アーバンライナーnextの「しんしい」を「あたらしい」に直し、京王2000系は裏付けられなかった座席切替の記述を、公式に確認できたひだまりスペースと大型窓の説明に置き換えた。名称変更を含むデータ変更は13件。

## 要件と差分

| ID | 状態 | 要件 |
| --- | --- | --- |
| REQ-001 | 維持 | 呼び名のなかった新幹線4件に列車名を併記する |
| REQ-002 | 維持 | 表記順をはやぶさ・こまちと同じ「形式名＋新幹線＋呼び名」に統一する |
| REQ-003 | 維持 | 形式・塗装と現在・過去の説明を保ち、各画面と読み上げで同じ表示名を使う |
| REQ-004 | 維持 | seedと公開JSONを同期し、スマートフォン・タブレット相当の画面で収まりを確認する |
| REQ-005 | 追加 | 登録110件の車両名を点検し、必要な名前と関連する明確な誤記を修正する |
| REQ-006 | 追加 | 全修正・検証後にmainへpushし、GitHub Pagesで公開されたデータと画面を確認する |

保留・削除する要件はない。追加依頼により、点検範囲を4件から全110件へ拡大し、当初は非対象だった公開・デプロイを対象に追加した。

## 受け入れ条件

- 選択肢、正解表示、図鑑一覧・詳細、読み上げに同じ呼び名と形式を使う。
- 今回変更する新幹線の表示名は、はやぶさ・こまちと同じく形式名を先頭、呼び名を「新幹線」の後ろに置く。E231系・E233系の近郊形には同じ路線名を付ける。
- 500系通常色とハローキティ新幹線を同じ4択に入れても区別できる。
- seedから公開JSONを再生成しても名前と説明が保持される。
- 390×844と820×1180で長い選択肢が折り返され、文字と聞き直しボタンがカード内に収まる。
- 登録110件、クイズ対象107件、図鑑109種類を維持する。
- mainのコミットとPagesの成功したビルドを照合し、公開URLが配信する110件のJSONと修正した名前・説明を確認する。

## 非対象

車両や写真の追加・差し替え、出題・採点方法、音声エンジン、全車両の写真・最新運行情報・全仕様の再監査。既に呼び名や路線名がある車両の一括改名は行わない。

## リスクと対策

- 同じ呼び名の車両がある：形式や塗装を省略せず、表示名全文を読み上げる。
- 現在と過去の列車名が混在する：図鑑説明で時代と運行区間を区別する。
- 名前が長くなる：既存の内容に合わせて伸びるカードで折り返しを確認する。
- 音声エンジンの英数字の発音は端末に依存する：発話に渡す文面のテストと、iPhone / iPad実機での聞こえ方の確認を区別する。

## 性能目標

追加ライブラリ・追加通信なし。既存データの名称・説明・運行会社を修正し、再生は従来どおり最大4発話とする。
