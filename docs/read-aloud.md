# 選択肢の読み上げモード

3歳で字をまだ読めない子どもが、写真と音声で4択を理解して答えられるようにする。主な利用端末はiPhone / iPad。

## 要件と操作

| ID | 状態 | 要件 |
| --- | --- | --- |
| REQ-001 | 追加 | タイトルと問題画面で読み上げをON/OFFにできる。初期OFF。同じブラウザに設定を保存する |
| REQ-002 | 維持 | ONで開始・次の問題・再挑戦を押すと、表示順に4択を日本語で読む。速度は標準の `rate = 1.0` |
| REQ-003 | 追加 | 「みずいろ・ぴんく・みどり・きいろ」と表示名を読み、発話開始イベントで該当カードの枠を強調する |
| REQ-004 | 追加 | 各カードの🔊でその選択肢だけを聞き直せる。再生ボタンは回答しない。「ぜんぶ きく」で全件を再生する |
| REQ-005 | 維持 | 色のついた名前のボタンを1回押すと回答する。既存の正誤判定と5問制を維持する |
| REQ-006 | 追加 | 回答、次問、結果、別画面、ページ非表示、OFF、聞き直しで古い発話を停止。遅れたイベントを無視する |
| REQ-007 | 追加 | 非対応、日本語音声なし、再生失敗を案内し、音声を使えなくてもクイズを続けられる |
| REQ-008 | 維持 | 全車両の名前全体を読み上げ時だけかなへ補正し、表示名・形式・塗装の区別を維持する |
| REQ-009 | 追加 | 全データの読みの登録漏れ・未変換文字をテストで検出し、全件再生と個別再生で同じ読みを使う |

2026-09-14の要件差分：REQ-002の速度をユーザー要望により `0.85` から `1.0` へ変更。REQ-008を追加。REQ-001、003〜007は従来の動作を維持し、保留・削除はない。

| --- | --- | --- |
| REQ-001〜007 | 維持 | 速度1.0、操作・停止・端末内音声の要件を維持 |
| REQ-008 | 維持 | かな補正を6路線の部分置換から全110件の全文へ拡張 |

| 保留・削除 | なし | 既存の要件は省略しない |

世界観は既存の「電車の写真・やさしい4色・丸いボタン」。音声と位置を結びつける色名は実際のボタン色と一致させる。回答と聞き直しは同じカード内の別ボタンにし、🔊の高さは56px以上とする。カードは内容に合わせて伸び、固定高さに押し込まない。

## 音声の扱い

Web Speech APIの`SpeechSynthesis`を使う。利用するのは日本語かつ`localService === true`の音声のみ。音声ファイルのダウンロード、音声API課金、マイク、録音は追加しない。名前は表示名の全文をもとにし、通常色や特別塗装、形式の区別を省略しない。速度は `rate = 1.0`。英数字を含む全文をかなで渡す。実際の所要時間・アクセント・声質は端末の音声エンジンに依存する。

`js/app.js` の全件再生・個別再生の共通入口で `js/train-readings.js` の全文読みを適用する。画面表示と車両データは変更しない。全110件の読みと特殊形式の根拠は [全車両の読み上げ用表記](train-readings.md) に記録する。前回の6路線の読みも全文辞書へ引き継いでいる。

| 表記 | 読み上げ用のかな |
| --- | --- |
| 山手線 | やまのてせん |
| 常磐線 | じょうばんせん |
| 京葉線 | けいようせん |
| 総武線 | そうぶせん |
| 京浜東北線 | けいひんとうほくせん |
| 横須賀線 | よこすかせん |

読みの参照：[JR東日本の教材（山手線・常磐線）](https://www.jreast.co.jp/id/akita/ietetsu/doc/accum-a.pdf)、[くもん出版の電車・地下鉄カード掲載名](https://shop.kumonshuppan.com/view/item/006001000074)。全110車両の実音声で誤読を点検したものではない。

ページ表示だけでは再生しない。保存済みONでも開始ボタンのタップを待つ。音声リストは再生のたびに取得し、日本語音声が後から利用可能になった場合は🔊で再試行できる。保存が拒否される環境では、その訪問中だけ設定を保持する。

初回発話・次の発話が8秒、1発話が30秒を超えてイベントが来ない場合は、キューを止めて再試行の案内を出す。ページに戻っても自動再開せず、🔊で再開する。

## 受け入れ条件

- ONで開始したとき、表示と同じ順序・色名で4択を読み、発話中だけそのカードが強調される。
- 全件再生・個別の聞き直しとも速度 `1.0` と全110件の全文かなを音声エンジンへ渡す。形式・塗装・番台・号機を省略しない。
- 🔊を連打しても回答や得点が変わらず、古い音声と重ならない。
- 回答後は古い発話を止め、個別の🔊を隠し、全件の再生を無効にする。「つぎへ ▶」を案内する。
- ON/OFFは再読み込み後も維持し、初期表示では音が出ない。
- iPhone相当390×844とiPad相当820×1180で横溢れがなく、カードの子要素が右端・下端に収まる。
- iPhone / iPadの実機Safariで、発音・音量・連打時の動作を最終確認する。

## 非対象

公開・デプロイ、図鑑や正誤結果の読み上げ、声の選択、録音音声、外部音声サービス、車両データや写真の変更。

## リスクと対策

- 日本語音声が端末にない／準備できていない：再試行できる案内を表示し、クイズ自体は止めない。
- モバイルの再生制限：開始・次へ・🔊のタップ内でキューへ登録。エラー時は🔊で再試行する。
- 写真と選択肢が離れる：モバイルの読み上げON時は見出しと空のフィードバック領域を詰め、写真と4択の距離を縮める。
- 固有名詞の誤読：全110件の全文をかなへ補正し、表示名の情報は省略しない。登録漏れを全データのテストで検出する。アクセントなどの品質は実機で確認する。

## 性能目標

外部ライブラリ・外部音声通信なし。全文辞書は静的JavaScriptモジュール1つで初回に読み込み、再生時のデータ取得は不要。1回の再生は最大4発話。操作時には古いキューを同期的に取り消し、画面遷移後に古い強調表示を残さない。
