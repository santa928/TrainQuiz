# ロマンスカー・私鉄・新幹線・観光列車の30種類追加

2026年9月8日確認。既存80件に30件を追記し、登録110件・クイズ対象107件とする。図鑑は同名のE5系2件をまとめる既存仕様により109種類を表示する。ロマンスカーは既存GSEと合わせて9種類。

## 要件と受け入れ条件

| ID | 状態 | 要件・受け入れ条件 |
| --- | --- | --- |
| REQ-001 | 維持 | 子どもが新しい電車を覚えられるよう20種類を追加し、全件が4択の正解として出題できる |
| REQ-002 | 追加 | ユーザーの希望を反映し、追加20種類のうち8種類をロマンスカーの別形式・改修車とする |
| REQ-003 | 維持 | 各車両に実写写真・著者・画像ライセンス・出典・図鑑の場所／区間／特徴／速さをそろえる |
| REQ-004 | 維持 | 元の80件、5問制、蒸気機関車のクイズ除外を保持する |
| REQ-005 | 追加 | 引退したロマンスカーの小田急での運行説明を過去形にし、EXEとEXEαなどを異なる写真で表示する |
| REQ-006 | 追加 | さらに良い候補を選んでPRにする依頼を反映し、新幹線・寝台列車・海や山の電車など10種類を加える。追加30種類すべてにREQ-001の出題条件とREQ-003の情報を適用する |

当初の「関東私鉄を中心に20種類追加」を維持し、その内訳にロマンスカー8種類を組み込んだ。追加依頼で、見た目だけでなく走る場所・役割も異なる10種類を加えた。保留・削除した要件はない。

## データと出典

`data/train-seeds.json` が正本。既存の `build_seed_record` で追加30件の公開レコードを生成し、既存の `data/trains.json` 80件は再取得せず保持する。今回の追加seedには確認した写真メタデータも固定し、記事の代表画像が変わっても別形式の写真に置き換わらないようにする。

車両の存在・特徴は次の鉄道会社のページで確認する。`productName` は既存スキーマ名を維持しているが、この追加分では車両名を意味する。プラレールの商品化・現行販売は追加条件にしない。

- 西武：[車両図鑑](https://kosodate.seiburailway.jp/kids/museum/zukan/)
- 東急：[2020・6020系](https://www.tokyu.co.jp/railway/trains/01/)、[5050系](https://www.tokyu.co.jp/railway/trains/02/)
- 相鉄：[電車車両図鑑](https://www.sotetsu.co.jp/life/gallery/train/)
- 京急：[車両紹介](https://www.keikyu.co.jp/ride/train/)、[ブルースカイトレイン](https://www.keikyu.co.jp/ride/train/keikyublueskytrain.html)

- JR西日本：[0系](https://www.westjr.co.jp/fan/paper/nostalgia/)、[サンライズ瀬戸・出雲](https://www.jr-odekake.net/railroad/train/sunriseseto_izumo/)
- 東武：[100系スペーシア](https://www.tobu.co.jp/railway/special_express/vehicle/spacia/)、[500系リバティ](https://www.tobu.co.jp/corporation/rail/vehicles/)
- 江ノ電：[300形](https://www.enoden.co.jp/fan/museum/vehicle/300/)、箱根ナビ：[登山電車の紹介](https://www.hakonenavi.jp/special/)

写真は各レコードの `imageSourceUrl` に示すWikimediaのファイルを確認し、EXE／EXEα、東急2020／6020／5050、京急の赤／青は別ファイルで固定する。東急5050系の記事は5000系の総合記事へ転送されるため、記事の代表画像は使わず5050系の写真を明示指定する。相鉄20000系の写真はファイル名に21000を含むが、写真の編成番号20103とファイル説明で20000系であることを確認する。

かもめもN700S系の総合記事の青帯写真を使わず、西九州用の赤白のY4編成を指定する。0系は運行説明を過去形にする。

速度は各レコードのWikipedia記事の営業速度欄で照合し、設計速度や試験記録と混同しない。小田急は小田急線内110km/h、西武は105km/h、東急は東急線内110km/h、京急は営業120km/hを記載。相鉄は[本線の営業最高速度100km/h](https://ja.wikipedia.org/wiki/相鉄本線)を採用し、`speedLabel` に相鉄線内の値であることを明示する。RSEも小田急線内の値を記載し、JR線内や譲渡後の速度とは分ける。

追加10件はE8系300、かもめ260、0系220、東武100／500系120、883／285系130、E261系120km/h。E8系は上記JR東日本、かもめは[長崎県の営業最高速度の説明](https://www.pref.nagasaki.jp/shared/uploads/2022/05/1652170695.pdf)、0系は[JR西日本の車両紹介](https://www.westjr.co.jp/press/article/2011/10/page_921.html)でも照合する。[江ノ島電鉄線](https://ja.wikipedia.org/wiki/江ノ島電鉄線)は45km/h、箱根3000形は記事に記載の箱根湯本〜強羅40km/hを採用し、区間を速度ラベルに明記する。

## 非対象

画面・クイズルール・出題頻度の変更、既存車両の全面再調査、新しい難易度やカテゴリ、公開・デプロイは含めない。

## リスクと対策

- 同系列の代表写真を誤って流用する：車両・塗装を目視し、形式ごとの写真を固定するテストを追加する。
- 引退車が現在も小田急で走るように読める：場所と区間を過去形にし、速さにも運行当時の注記を入れる。HiSE・RSEの譲渡先での運行は説明対象にしない。
- 画像の外部配信が遅い・停止する：既存の画像読み込み処理を使用し、今回の30画像は実ブラウザで読み込みを確認する。将来の外部配信の可用性は保証しない。
- 出典サイトの自動取得制限：E8・サフィールのページはPythonから403、0系のページは既存取得処理のUTF-8固定でデコードエラーとなったため、Web閲覧で照合した。確認済みseedからのレコード生成は可能だが、ネットワーク付き一括再生成は今回成功確認できていない。サンライズの移転先はseedに反映した。

## 性能目標と検証

既存の静的JSON読み込みと遅延画像読み込みを維持し、新しい依存や起動時通信処理を増やさない。登録110件・図鑑109種類で一覧表示と詳細への遷移が操作できることを代表画面で確認する。

Docker内でデータ形状・seed同期・クイズ生成・追加30件の回帰テストを実行する。ブラウザで写真30件の読み込みと形式の一致を確認し、スマートフォン相当の画面で図鑑詳細とクイズの表示・操作を確認する。UIや共有ロジックを変更しないため、全ブラウザ・Lighthouse・公開URL検証は今回の対象外。公開時、または画像読み込み方式・レイアウト変更時に必要な検査を追加する。

確認結果：

- 最終30件でDocker / Node 22の `tests/data-shape.test.mjs`、`tests/quiz-engine.test.mjs`、`tests/train-expansion.test.mjs` の25テストが成功。最初の20件を追加する前には、新規3テストが未登録データを検出して失敗することも確認した。
- 元のseed・配信データ各80件の値と順序が変わっていないこと、追加30件がseedから同じ公開レコードに再生成できることを照合した。
- 実ブラウザで追加30画像の読み込み完了と形式・塗装を目視確認。
- 390×844の表示でVSEとブルースカイトレインの詳細に横はみ出しがないことを確認。追加した西武30000系を含む5問を回答し、5問正解の結果画面まで到達した。
- 最終データを読み直して図鑑の109種類表示と箱根アレグラ号の詳細遷移を確認。390×844で横はみ出しがなく、説明・比較・画像出典まで表示できることを目視確認した。
